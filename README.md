# 🌻 Feliz día de las flores amarillas — Nana

Animación web hecha con HTML, CSS y JavaScript.

### Secuencia

1. Girasol grande inicial.
2. Al tocarlo comienza la música.
3. Cae una semilla.
4. Desaparece la semilla.
5. Crece la silueta café del árbol.
6. Aparecen muchos girasoles visibles, con pétalos amarillos y centro marrón.
7. Los girasoles llenan una forma matemática de corazón.
8. Aparece el mensaje.
9. Termina con: **“Te quiero, te quiero Nana ♥”**
10. Empieza una lluvia de girasoles.

### Música

Si quieres poner una canción específica, coloca tu MP3 en:

`assets/musica.mp3`

Debe ser una canción que tengas permiso para utilizar/publicar.

## 🎵 Música incluida
La canción está incluida en `assets/musica.mp3`. El sitio intenta reproducirla cuando se toca el girasol inicial.
